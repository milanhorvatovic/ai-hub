## Getting started

1. Fork and clone the repository.
2. Install the toolchain and dependencies: `<setup command>`.

> Detailed environment setup lives in <link to dev setup / README>.

## Making a change

- Create a topic branch from the default branch.
- Keep changes focused; one logical change per pull request.
- Add or update tests for any behavior change.
- Run `<lint command>` and `<test command>` before pushing.

## Pull requests

- Fill in the PR template; describe what changed and why.
- Link the issue it addresses.
- Expect review from a code owner; address feedback by pushing follow-up commits.
